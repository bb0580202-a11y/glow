# 萤 · 暖光粒子

纯黑底上的暖光萤火,会被你的鼠标/手指/手势吸引、聚拢、散开。原生 Canvas 2D,单文件,无构建无依赖。

## 怎么开 / 怎么玩

**方式一:双击启动(摄像头要用这个)**
1. 双击 `start.command` —— 自动起本地服务并打开浏览器(localhost:8137)。
   - 首次若被 macOS 拦截(身份不明开发者):右键 `start.command` → 「打开」一次,以后直接双击。
2. 鼠标移动 / 触摸拖动 → 附近萤火被吸引、聚拢,移开散回。
3. 点左下角「开启摄像头」→ 允许授权 → 用手控制:
   - **张开手掌 → 推散**(右下角显示「散」)
   - **握拳 → 强聚**(显示「聚」)
   - 平手 / 自然 → 轻柔吸引(显示「·」)

**方式二:直接双击 `index.html`** —— 只有鼠标/触摸版(浏览器规定摄像头只能在 localhost/HTTPS 用,`file://` 不行)。

## 怎么关

关闭双击 `start.command` 后弹出的那个**终端窗口**即停止服务(或在该窗口按 `Ctrl+C`)。

## 调参

视觉/手感参数都集中在 `index.html` 顶部的 `CONFIG`(粒子数、颜色、吸引力、手势阈值、暗蒙版等),改完刷新即可。

## 文档

设计与实现计划在 `docs/superpowers/` 下(spec + plan),含物理模型(Ornstein–Uhlenbeck 布朗运动、平方反比发光)与摄像头/手势方案。
